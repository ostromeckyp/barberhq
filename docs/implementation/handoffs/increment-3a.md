## Storage relationship

Original immutable PDF bytes live in private Firebase Storage. PostgreSQL holds document/version metadata, extracted readable text, physical-page geometry, chunks and embedding vectors. PDF.js extracts text and coordinates from the actual PDF; Markdown is an authoring input/derived artifact, never a substitute for parsing the PDF that the viewer displays.

## Authorized source and viewer

`getSourcePdf` accepts only a version ID, verifies Auth (including revocation) and production App Check, checks exact allowed browser origins, and resolves tenant membership and eligible source identity in SQL. Published historical READY versions remain readable unless revoked; unpublished previews require HQ. The stored generation, byte count and SHA-256 identify the original. Reads are bounded to 10 MiB and returned as private, no-store PDF bytes; no public Storage URL is issued.

`GetSourceSection` supplies authorized version/chunk metadata, geometry and page text. A chunk must belong to its version and determines the physical page. The Angular route is `/procedures/sources/:versionId?page=N&chunk=CHUNK_ID`. It supports page-only links, page/zoom/rotation controls, authorized download, provenance labels, excerpts and an explicit unavailable-highlight fallback.
