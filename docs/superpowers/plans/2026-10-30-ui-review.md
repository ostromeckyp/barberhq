# UI review fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the 17 UI review findings: loaders, 390 px layout, and one look for back, refresh, quantities and empty states.

**Architecture:** Shared pieces first (`app-back-link`, page-header action gap, quantity class, nav wrapping, splash), then per-feature fixes that use them. Web only; no backend change.

**Tech Stack:** Angular 22 standalone + signals (zoneless), Angular Material, Transloco, Vitest (`npm run test:web`), Playwright e2e against emulators.

**Spec:** `docs/superpowers/specs/2026-10-30-ui-review-design.md` (finding numbers below refer to it).

## Global Constraints

- Every new or changed user-visible text is a Transloco key present in both `web/public/i18n/en.json` and `web/public/i18n/pl.json`; `npm run test:unit -- tests/unit/i18n-keys.test.ts` passes.
- Code-structure rules in `tests/unit/code-structure.test.ts`: one exported model per file, logic files ≤ ~300 lines.
- Shared components live in `web/src/app/shared/ui/<name>/` and are listed in `web/src/app/shared/ui/README.md`.
- No behavior change beyond the spec; no Functions, schema or connector change.
- Gates per task: `npm run typecheck`, `npm run test:web`, `npm run test:unit`, `npm run format:check`.
- E2E selectors change only where markup changed on purpose; run the affected e2e specs with `BARBERHQ_TEST_MODE=emulator npx playwright test <spec>` (emulators on, dev server on 4200).

## Review Focus

- Polish strings are longer than English: at 390 px the request filter, HQ toggle and back links must not wrap or overflow in Polish.
- A product that fails to load in the editor must not leave an enabled empty form that can be saved.
- Language switch while a page is open: new labels (outcome copy, card title, back links) re-render in the new language (keys, not stored text).
- Keyboard users: `app-back-link` and the HQ toggle stay reachable and announce their names.
- Splash must not flash after bootstrap and must not show on pages Angular has already rendered (it lives inside `<app-root>`).
